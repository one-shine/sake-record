リリース手順を実行する。対象: $ARGUMENTS

1. `git status` がクリーンで、対象ブランチが最新か確認する。
2. テスト全実行・型チェック・lint を通す（失敗したら根本原因を直す。抑制しない）。
3. ビルドが成功することを確認する。
4. 同梱 `/security-review` で差分のセキュリティ問題(秘密の混入・入力検証・認可)を確認する。
5. 主要動線(登録〜中核機能)を手動 or e2e で1周確認し、エラー画面・リンク切れがないか見る。
6. 変更点を要約したコミットメッセージを作り、コミットする。
7. 不可逆・対外的な操作(本番デプロイ・公開・課金本番値)は実行前に必ず確認を取る。
8. PR を作成し、検証の証拠(テスト出力・スクショ)を本文に添える。
